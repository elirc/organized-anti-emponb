# Module 06: Live Practice Tracks

This module presents active, hands-on development tracks designed to test your knowledge in the real codebase laboratory. You will find reading katas, modify tickets, deep build projects, and open-source contribution guidelines.

---

## Contents Covered in This Module

1. **[01-reading-katas.md](01-reading-katas.md)**: 10 structural codebase traces requiring you to locate and explain critical platform execution paths.
2. **[02-modify-tickets.md](02-modify-tickets.md)**: 10 progressive, real-world modify tickets ranging from basic validation adjustments to expert transactional refactoring.
3. **[03-build-projects.md](03-build-projects.md)**: 5 comprehensive extension projects (such as implementing Slack integrations or task SLA tracking) using the codebase as a foundation.
4. **[04-senior-katas.md](04-senior-katas.md)**: Advanced system design exercises focusing on distributed locks, caching invalidation, and data synchronization.
5. **[05-oss-contribution-guide.md](05-oss-contribution-guide.md)**: Git branching strategies, pull request blueprints, and code style parameters.

---

## Learning Objectives

* Read and parse complex, unfamiliar code paths using precise tool tracing.
* Implement progressive codebase revisions that satisfy automated unit testing.
* Formulate complete architectural extension blueprints.
* Adhere to strict, professional open-source contributing standards.
