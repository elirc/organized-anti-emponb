# Module 07: Career Skills and Review

Transitioning to a senior software engineer requires more than just technical brilliance; it requires leadership, effective communication, structural RFC pitches, and rigorous peer review mentoring. This module details these core professional capabilities.

---

## Contents Covered in This Module

1. **[01-code-review-mindset.md](01-code-review-mindset.md)**: Peer review ethics, delivering constructive architectural feedback, and automated lint checkers.
2. **[02-writing-prs-and-rfcs.md](02-writing-prs-and-rfcs.md)**: Request for Comments (RFC) templates, drafting design proposals, and pitching architecture.
3. **[03-interview-prep.md](03-interview-prep.md)**: Technical and behavioral interview scenarios mapped directly to our monorepo codebase (using STAR structures).

---

## Learning Objectives

* Review peer pull requests constructively, highlighting structural design trade-offs.
* Author clear, actionable Request for Comments (RFC) proposals for systemic code refactoring.
* Formulate robust behavioral interview responses that showcase complex technical decision-making capabilities.
